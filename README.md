# SDR
Formulas for expected values of Successive Difference Replication under Simple Random Sampling without Replacement.

This package supplements the work found in the citation below. While the package itself provides a small vignette validating the equivalency of the three versions of the variance estimation, the separate SDRpkg.RLog file provides further examples to support the assertions made in the paper.
